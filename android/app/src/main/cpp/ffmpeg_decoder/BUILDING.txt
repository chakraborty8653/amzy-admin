FFmpeg E-AC-3 decoder build

The app bundles FFmpeg 6.0 with only the E-AC-3 decoder enabled. The source
archive and LGPL 2.1 license are in app/src/main/assets/licenses.

Build the native libraries from WSL/Linux:

1. Install Android NDK r28b, CMake, Ninja, make, yasm, and git.
2. Extract FFmpeg-6.0-source.tar.gz to this directory as jni/ffmpeg.
3. Run:

   bash jni/build_ffmpeg.sh "$PWD" "$ANDROID_NDK_HOME" linux-x86_64 24 eac3

4. For each Android ABI, build the JNI wrapper with CMake:

   cmake -S jni -B build/arm64-v8a \
     -DCMAKE_TOOLCHAIN_FILE="$ANDROID_NDK_HOME/build/cmake/android.toolchain.cmake" \
     -DANDROID_ABI=arm64-v8a -DANDROID_PLATFORM=24 \
     -DANDROID_STL=c++_static -DCMAKE_BUILD_TYPE=Release
   cmake --build build/arm64-v8a --parallel

Repeat step 4 with ANDROID_ABI set to armeabi-v7a, x86, and x86_64, then copy
each build's libffmpegJNI.so to app/src/main/jniLibs/<ABI>/.

The Java renderer sources are in app/src/main/java/androidx/media3/decoder/ffmpeg
and are based on AndroidX Media3 1.5.1.
